## 結論

> 結論：ファイブフォース分析は「その業界は儲かりやすいか」を判断する道具です。5つの力が強いほど、業界の利益は削られます。経営学者のマイケル・ポーターが1979年に発表し、翌年の著書『競争の戦略』で体系化しました。

業界の儲かりやすさは、自社の努力だけでは変えにくい「前提条件」です。ファイブフォース分析で前提を確認したうえで、その業界でどう戦うか（3つの基本戦略など）を考えます。

## 5つの競争要因と、力が強くなる条件

| 競争要因 | 分析の視点 | 力が強くなる（儲かりにくくなる）条件 |
|---|---|---|
| 業界内の競争 | 競合の数、市場規模と成長性、差別化の度合い | 競合が多い、市場の成長が遅い、製品に差がない、固定費が大きい、撤退障壁が高い |
| 新規参入の脅威 | 参入障壁の高さ、既存企業の反撃の可能性 | 参入障壁が低い、既存企業が反撃しない |
| 代替品の脅威 | 代替品の価格と性能、乗り換えのしやすさ | 代替品のコストパフォーマンスがよい、乗り換えのコストが低い |
| 売り手（仕入先）の交渉力 | 仕入先の数と力関係、仕入先を替えるコスト | 仕入先が少数で寡占、替えのきかない原材料、仕入先を替えるコストが高い |
| 買い手（顧客）の交渉力 | 顧客の数と集中度、購買量、製品の独自性 | 顧客が少数で大口、製品に差がない、顧客が自分で作れる（後方統合の脅威） |

## ポーターが挙げた7つの参入障壁

| 参入障壁 | 内容 | 例 |
|---|---|---|
| 規模の経済 | 大量に生産しないとコストで勝てない | 自動車、鉄鋼 |
| 製品差別化 | 既存のブランドや顧客の愛着がある | 飲料、化粧品 |
| 巨額の投資 | 参入に大きな資金が必要 | 航空、通信 |
| 仕入先を替えるコスト（スイッチングコスト） | 顧客が乗り換えるのに手間やコストがかかる | 業務用ソフト |
| 流通チャネル | 販路を確保するのが難しい | 自動販売機網、問屋との取引 |
| 規模以外の要因によるコスト差 | 立地、技術、経験による既存企業のコスト優位 | 好立地の店舗、特許 |
| 政府の政策 | 許認可や規制がある | 建設業、医療、酒類販売 |

> ポイント：中小企業にとって身近な参入障壁は、「許認可」「地域の取引先との信頼関係」「専門の技術者」です。逆に、これらがない業界は、すぐに競合が増えると考えておく必要があります。

## 業界構造の5つのタイプ

ポーターは、業界の状況によって有効な戦略が変わるとしました。

| タイプ | 状況 | 有効な戦略 |
|---|---|---|
| 多数乱戦業界 | 小さな企業が入り乱れ、主導権を握る企業がない | 集約・統合で規模を大きくし、規模の経済が働く状態をつくる。または特定の顧客・地域に専門化する |
| 新興業界 | 技術革新などで新しく生まれた業界 | 先行者として地位を築き、経験曲線効果を働かせる。業界の標準づくりを主導する |
| 成熟業界 | 成長が鈍り、シェアの奪い合いが激しい | 品質向上やコスト削減を徹底する。製品の種類を絞り、既存顧客への販売を増やす |
| 衰退業界 | 需要が長期的に減っている | 4つの戦略から選ぶ（下表） |
| グローバル業界 | 国境を越えて競争している | グローバル戦略（I-Rフレームワーク）で統合と現地適応を考える |

### 衰退業界の4つの戦略

| 戦略 | 内容 |
|---|---|
| リーダーシップ戦略 | 競合の撤退を促し、残った市場で主導権を握る |
| ニッチ戦略 | 需要が安定している特定の分野に絞って残る |
| 刈り取り戦略 | 投資を抑えて、手元に資金を回収しながら段階的に縮小する |
| 即時撤退戦略 | できるだけ早く事業を売却・撤退する |

> 補足：地方の商店街の小売業や、紙の印刷業などは、衰退業界の戦略が当てはまる典型です。「最後の1社として残る（リーダーシップ）」「特定の顧客だけに絞る（ニッチ）」という選択肢があることを知っておくと、撤退以外の道が見えてきます。

## 中小企業での使い方

1. **自社の業界を1つの表にまとめる**：5つの要因ごとに「強い・中・弱い」を判定し、理由を1行で書きます。
2. **一番強い力を特定する**：利益を削っている最大の要因に、打ち手を集中させます。
3. **打ち手を考える**：

| 強い力 | 打ち手の例 |
|---|---|
| 買い手の交渉力 | 取引先を分散し、1社への売上依存を30%以下に下げる |
| 売り手の交渉力 | 仕入先を複数にする、共同仕入れを行う |
| 新規参入の脅威 | 資格や許認可、地域の信頼関係を強みとして打ち出す |
| 代替品の脅威 | 代替品にはない価値（対面のサポート、即日対応）を強化する |
| 業界内の競争 | 差別化集中戦略で、競争の少ない分野に移る |

## 試験対策のポイント

- **5つの要因の名前**：「供給業者（売り手）」「買い手」「新規参入」「代替品」「業界内の競争」。
- **力が強くなる条件の向き**：「買い手が少数で大口なら、買い手の交渉力は強い」など、向きを逆にした選択肢がよく出ます。
- **撤退障壁が高いと競争は激しくなる**：利益が出なくても企業が残り続けるためです。
- **衰退業界の4戦略**：リーダーシップ・ニッチ・刈り取り・即時撤退。

## よくある誤解

1. **「5つの力は自社への脅威の一覧」**：ファイブフォースは「業界全体」の収益性を見る道具です。自社の強み・弱みはVRIOやSWOTで見ます。
2. **「競合は同業者だけ」**：代替品も競争相手です。顧客の同じ困りごとを解決するものは、業種が違っても競合になります。
