## 結論

> 結論：ネット通販で消費者に売るなら、特定商取引法の通信販売のルールに従い、広告に、価格と送料、支払と引渡しの時期、返品のルール、事業者の氏名・住所・電話番号などを表示します。
>
> 2022年6月からは、注文を確定する直前の最終確認画面にも、分量・価格・支払・引渡し・申込期間・解約の6項目の表示が義務になりました。通信販売にクーリング・オフはありませんが、返品の可否を表示していないと、商品が届いてから8日以内は返品を受けなければなりません。

## 対象になる取引

通信販売は、郵便、電話、インターネットなどで申込みを受ける取引です（電話勧誘販売に当たるものを除く）。自社のサイトだけでなく、モールへの出店、SNSやメッセージアプリで注文を受ける場合も含みます。

事業者が営業のために買う取引は対象外なので（26条1項1号）、法人だけを相手にする卸売のサイトには、このルールはかかりません。

経済産業省の調査では、2025年の消費者向けの電子商取引は27.6兆円で、物販に占めるネット販売の割合（EC化率）は9.80%でした。

## 広告に表示する事項（11条）

| 事項 | 書き方の例 |
|---|---|
| 販売価格（役務の対価）と送料 | 税込価格。送料が地域で違うなら地域ごとの額 |
| 代金の支払時期と支払方法 | 前払い、後払い、クレジットカード、代金引換 |
| 商品の引渡時期（役務の提供時期） | ご注文から3営業日以内に発送 |
| 申込みの期間の定め | 期間限定で売るなら、その期間 |
| 申込みの撤回・契約の解除（返品特約） | 返品できるか、条件、返品の送料をどちらが負担するか |
| 事業者の氏名（名称）、住所、電話番号 | 法人は登記上の名称と住所。個人事業主は戸籍上の氏名か登記した商号 |
| 代表者または通信販売の業務の責任者の氏名 | 法人がネットで広告する場合 |
| 価格と送料以外に購入者が負担する金銭 | 振込手数料、組立費 |
| 不良品などの責任の定め | 交換・返金の条件 |
| ソフトウエアの動作環境 | ソフトウエアを売る場合 |
| 2回以上の契約が必要なとき（定期購入）の条件 | 回数、各回の代金、総額 |
| 販売数量の制限など特別な条件 | お一人様3点まで |
| 電子メールで広告するときのメールアドレス | メールマガジンなどの場合 |

消費者から請求があれば遅れずに書面やメールで提供すると広告に示し、実際に提供できる体制を整えている場合は、一部の事項を省略できます。

広告で、商品の性能や返品の条件などを、事実と著しく違う内容や、実際より著しく良く見せる内容で示すことは禁止されています（12条、誇大広告の禁止）。商品の表示そのものには景品表示法もかかります。

## 最終確認画面の6項目（12条の6、2022年6月から）

申込みボタンを押すと注文が確定する画面（最終確認画面）には、次の6つを表示します。

1. 分量（数量、定期購入なら回数や期間）
2. 販売価格・対価（送料を含む）
3. 代金の支払時期と方法
4. 商品の引渡時期（役務の提供時期）
5. 申込みの期間（期限がある場合）
6. 申込みの撤回・契約の解除に関する事項（返品特約、定期購入の解約方法など）

注文が定期購入ではないと思わせる表示など、消費者を誤認させる表示も禁止されています。違反する表示を見て誤認して申し込んだ消費者は、申込みを取り消せます（15条の4）。

消費者庁のガイドラインは、画面に注文内容の最終確認といった表題を付け、最終確認画面だと分かるようにすることが望ましい、としています（2024年11月の改正で追加）。

## 返品特約と8日ルール（15条の3）

通信販売には、訪問販売のようなクーリング・オフはありません。その代わりに、返品の可否と条件（返品特約）を表示していない場合は、商品を受け取った日から数えて8日以内なら、購入者は契約を解除して返品できます。返品の送料は購入者の負担です。

返品を受けない、未開封に限るなどの特約を、広告と最終確認画面に分かりやすく表示していれば、特約が優先します。消費者庁のガイドラインは、価格や電話番号の近くに同じ大きさの文字で示すなど、他の情報に埋もれない表示を求めています。

届いた商品が壊れていた、注文と違っていた、という場合は、返品特約とは別の問題です。民法の契約不適合責任にもとづき、交換や返金に応じます。

## 2026年の見直しの動き

消費者庁の「デジタル取引・特定商取引法等検討会」は、2026年9月10日に中間取りまとめを公表しました。消費者を誤った判断に誘う画面の設計（ダークパターン）、解約の手続きを難しくすること、SNSのチャットでの勧誘などへの対応が論点です。

意見募集は2026年10月31日に締め切られました。2026年11月時点で、法改正は成立していません。最終確認画面と解約の手順は、改正を待たずに今のルールで見直しておくと、後の対応も軽くなります。

## 開設前のチェックリスト

- 特定商取引法にもとづく表記のページに、上の表の事項がそろっているか
- 送料、振込手数料など、価格以外の負担がすべて書かれているか
- 最終確認画面に6項目があり、リンク先に飛ばさなくても読めるか
- 返品特約が、商品ページと最終確認画面の両方に、目立つ形で書かれているか
- 定期購入なら、回数、各回の代金、総額、解約の方法が最終確認画面にあるか
- メールマガジンを送るなら、受信の同意を取っているか

広告メールの同意のルールは「[営業メールと特定電子メール法](/posts/tokutei-denshi-mail-sales/)」、販路の選び方は「[販路開拓の方法と小規模事業者持続化補助金](/posts/sales-channel-jizokuka-hojokin/)」で扱っています。

## ひとことで言うと

> ポイント：ネット通販は、広告に価格・送料・支払・引渡し・返品・事業者情報を、最終確認画面に分量・価格・支払・引渡し・申込期間・解約の6項目を表示します。返品特約を書かないと、到着から8日以内は返品を受けることになります。
