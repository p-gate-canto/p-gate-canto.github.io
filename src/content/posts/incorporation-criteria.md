## 結論

> 結論：法人成りの目安は、税率だけで見れば、個人の課税所得が330万円を超えたあたりからです。ここから所得税と住民税の上乗せ分の税率が約30%になり、中小法人の税率（約21〜23%）を上回ります。
>
> ただし、法人にすると社長1人でも社会保険への加入が必要になり、毎年の固定費もかかります。消費税では、2027・2028年分の「3割特例」が個人事業者だけの制度です。税率の差に加えて、社会保険、消費税、費用、信用の5つの軸で試算してから決めます。

## 5つの判断軸

| 軸 | 個人事業 | 法人 |
|---|---|---|
| 1. 税率 | 所得税5〜45%（累進）＋住民税10%＋個人事業税（業種により0〜5%） | 中小法人の実効税率 約21〜34% |
| 2. 社会保険 | 国民健康保険と国民年金（従業員5人以上の一定の業種などを除く） | 社長1人でも健康保険・厚生年金に加入 |
| 3. 消費税 | 2027・2028年分は3割特例を使える場合がある | 3割特例はない。設立当初は免税の場合もある |
| 4. 費用 | 開業の届出だけ | 設立の登録免許税、毎年の均等割（最低7万円）、税理士報酬など |
| 5. 信用・承継 | 事業用の財産は個人のもの | 取引や融資、採用で信用を得やすい。株式で事業を引き継げる |

## 1. 税率：上乗せ分の負担で比べる

利益が1万円増えたときに、何%が税金になるか（限界税率）で比べます。個人は所得税と住民税、法人は法人税・住民税・事業税の合計。

| 個人の課税所得 | 個人（所得税＋住民税） | 法人の所得 | 法人（実効税率） |
|---|---|---|---|
| 195万円以下 | 約15% | 400万円以下 | 約21.4% |
| 195万円超330万円以下 | 約20% | 400万円超800万円以下 | 約23.2% |
| 330万円超695万円以下 | 約30% | 800万円超 | 約33.6% |
| 695万円超900万円以下 | 約33% | | |
| 900万円超1,800万円以下 | 約44% | | |
| 1,800万円超4,000万円以下 | 約51% | | |

個人の欄は、所得税（復興特別所得税を含む）と住民税10%の合計です。個人事業税がかかる業種なら、さらに最大5%の上乗せ。法人の欄は、資本金1億円以下の会社の標準的な税率で、事業税が翌期の損金になることを織り込んだ実効税率です。

表から読み取れるのは、個人の課税所得が330万円を超えると、上乗せ分の税率は法人のほうが低い、ということ。695万円を超えると、差は10ポイント以上に開きます。

では、法人にすれば税金は単純に減るのか。会社に残した利益は、社長個人のお金ではありません。個人で使うには、役員報酬か配当として受け取り、そこでまた税金がかかります。法人成りで税金が減る理由は、主に次の3つ。

- 役員報酬に給与所得控除が使える（個人事業の所得には使えない）
- 所得を社長個人と会社に分けて、どちらも低い税率の帯に収められる
- 退職金を受け取るとき、退職所得控除と2分の1課税が使える

報酬と配当の配分による手取りの違いは「[役員報酬と配当はどちらが得か](/posts/officer-pay-vs-dividend/)」で試算しています。

## 2. 社会保険：社長1人でも加入が必要

法人の事業所は、社長1人だけでも健康保険と厚生年金の適用事業所になります（健康保険法3条、厚生年金保険法6条）。役員報酬にかかる保険料は、40〜64歳なら会社負担が約15.4%、本人負担が約15.0%です（協会けんぽ東京支部、2026年10月分から）。

個人事業のときの国民健康保険と国民年金と比べれば、負担は増えるのが普通。一方で、厚生年金の分だけ将来の年金が増え、病気やけがで働けないときの傷病手当金も受けられます。税金が減った分を、社会保険料の増加が上回らないかを、必ず一緒に試算します。

## 3. 消費税：個人の3割特例がなくなる

インボイスの登録を機に課税事業者になった個人事業者は、2027年分と2028年分の消費税を、売上の消費税額の30%で納められる「3割特例」を使える場合があります。法人には、この特例がない。ここが2027年・2028年に法人成りを考えるときの落とし穴です。

| 場面 | 個人事業のまま | 法人成りした後 |
|---|---|---|
| 売上の消費税額50万円のサービス業 | 3割特例で15万円 | 簡易課税（みなし仕入率50%）で25万円 |

資本金1,000万円未満で設立した法人は、最初の2期は消費税が免税になる場合があります。ただし、取引先からインボイスを求められて登録すると、その時点から課税事業者です。3割特例の要件と計算は「[2割特例はいつまで？](/posts/invoice-2wari-3wari-tokurei/)」で扱っています。

## 4. 費用：設立のときと毎年

| 費用 | 株式会社 | 合同会社 |
|---|---|---|
| 登録免許税 | 資本金の0.7%（最低15万円） | 資本金の0.7%（最低6万円） |
| 定款の認証手数料 | 数万円（資本金などによる） | 不要 |
| 定款の収入印紙 | 4万円（電子定款なら不要） | 同左 |
| 毎年の均等割 | 最低7万円（赤字でもかかる） | 同左 |

このほか、法人の申告は個人より複雑で、税理士報酬も高くなるのが一般的。社会保険の手続き、給与計算、決算公告（株式会社）などの事務も増えます。均等割は「[法人住民税の均等割とは](/posts/kintowari/)」で扱っています。

## 5. 信用と事業の引き継ぎ

法人にすると、取引先の与信審査や金融機関の融資、採用で、信用を得やすくなります。事業を後継者に渡すときも、株式を移す形で引き継げるのが法人の強み。

一方で、会社のお金と社長個人のお金ははっきり分かれます。会社のお金を個人のために使えば役員への貸付金になり、利息や返済の扱いを問われます。

## 法人成りした後の届出の期限

| 届出 | 提出先 | 期限 |
|---|---|---|
| 法人設立届出書 | 税務署 | 設立の日から2か月以内 |
| 青色申告の承認申請書 | 税務署 | 設立の日から3か月を経過した日と、最初の事業年度の終了の日の、早いほうの前日まで |
| 給与支払事務所等の開設届出書 | 税務署 | 開設の日から1か月以内 |
| 健康保険・厚生年金保険 新規適用届 | 年金事務所 | 適用事業所になった日から5日以内 |
| 個人事業の廃業等届出書 | 税務署 | 廃業の日から1か月以内 |

青色申告の承認申請を出し忘れると、最初の期が白色申告になり、赤字を繰り越せません。源泉所得税の納期の特例も、あわせて出しておくと手間が減ります。

## よくある誤解

### 「売上が1,000万円を超えたら法人成り」

判断の基準は、売上ではなく所得（利益）。売上が多くても利益が少なければ、法人成りで税金はほとんど減らず、固定費と社会保険料だけが増えます。

### 「法人にすれば何でも経費になる」

経費（損金）になるかどうかの基準は、個人も法人も「事業のための支出か」で変わりません。役員報酬も、期の途中で自由に変えると損金になりません。

## 実務メモ

> 補足：【実務メモ】筆者が法人成りの相談を受けるきっかけで多いのは、確定申告で税額に驚いたときです。所得税に住民税と国民健康保険料を合わせた負担を見て、相談に来られます。ただ、法人成りの損得は社会保険料と手間まで含めて決まるため、税額の大きさだけで時期を決めず、本文の5つの軸で試算してから判断します。

## ひとことで言うと

> ポイント：税率だけなら、個人の課税所得が330万円を超えると法人のほうが上乗せ分の税率は低くなります。ただし社会保険料の増加、法人の固定費、個人だけの消費税3割特例を差し引くと、損益の分かれ目はもっと上です。5つの軸で試算してから決めます。
