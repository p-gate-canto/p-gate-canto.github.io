## 結論

> 結論：粗利（売上総利益）は「商品やサービスそのものの稼ぐ力」、営業利益は「本業の稼ぐ力」、経常利益は「借入の利息なども含めた、会社のふだんの稼ぐ力」を表します。金融機関が特に重視するのは経常利益です。

損益計算書は、売上から順番に費用を差し引いていく形になっています。上から読むほど「本業に近い利益」、下に行くほど「会社全体の最終的な利益」になります。

## 5つの利益の比較表

| 利益 | 計算式 | 表すもの |
|---|---|---|
| 売上総利益（粗利） | 売上高 － 売上原価 | 商品・サービスそのものの稼ぐ力 |
| 営業利益 | 売上総利益 － 販売費及び一般管理費 | 本業の稼ぐ力 |
| 経常利益 | 営業利益 ＋ 営業外収益 － 営業外費用 | 財務活動も含めた、ふだんの稼ぐ力 |
| 税引前当期純利益 | 経常利益 ＋ 特別利益 － 特別損失 | 臨時の損益も含めた利益 |
| 当期純利益 | 税引前当期純利益 － 法人税等 | 最終的に会社に残る利益 |

## 数値例で見る

| 項目 | 金額 | 利益 |
|---|---|---|
| 売上高 | 10,000千円 | |
| 売上原価 | △6,000千円 | |
| | | **売上総利益 4,000千円** |
| 販売費及び一般管理費（人件費・家賃など） | △3,200千円 | |
| | | **営業利益 800千円** |
| 営業外収益（受取利息など） | ＋50千円 | |
| 営業外費用（支払利息など） | △150千円 | |
| | | **経常利益 700千円** |
| 特別損失（固定資産の売却損など） | △100千円 | |
| | | **税引前当期純利益 600千円** |
| 法人税等 | △180千円 | |
| | | **当期純利益 420千円** |

検算：4,000－3,200＝800、800＋50－150＝700、700－100＝600、600－180＝420。

## どの利益を見ればよいか

| 見る人・場面 | よく見る利益 | 理由 |
|---|---|---|
| 値決め・商品の見直し | 粗利 | 商品ごとの採算が分かる |
| 本業の改善 | 営業利益 | 人件費や家賃を含めた本業の実力が分かる |
| 金融機関の融資審査 | 経常利益 | 利息を払ったあとでも、毎年利益が出ているかが分かる |
| 株主・配当 | 当期純利益 | 配当や内部留保の元手になる |

> ポイント：営業利益は黒字なのに経常利益が赤字なら、借入の利息が本業の稼ぎを上回っています。返済計画や借り換えを検討するサインです。

## 「粗利」の呼び方に注意

一般に「粗利」は売上総利益を指します。ただし、業種や会社によっては、売上から変動費だけを差し引いた「限界利益」を粗利と呼ぶこともあります。社内や顧問先と話すときは、どちらの意味かをそろえておきましょう。限界利益については「[限界利益と損益分岐点の計算](/posts/contribution-margin-breakeven/)」で整理しています。
