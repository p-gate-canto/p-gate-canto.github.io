## 結論

> 結論：事業部の業績評価と、事業部長の業績評価は、別の利益で行います。事業部の評価は、事業部が会社全体の利益にどれだけ貢献しているかを示す事業部貢献利益で行い、存続・撤退・投資の判断に使います。事業部長の評価は、事業部長が自分の権限で動かせる収益と費用だけで計算した管理可能利益で行います。
>
> 責任者は、自分が管理できる数字で評価する、というのが管理可能性の原則です。事業部長が決められない本社の設備投資の減価償却費や本社費まで含めて評価すると、努力と結果が結びつかず、評価への納得が得られません。

## 2つの評価の違い

| 項目 | 事業部の業績評価 | 事業部長の業績評価 |
|---|---|---|
| 評価するもの | 経済的な単位としての事業部 | 事業部を任された管理者 |
| 使う利益 | 事業部貢献利益（管理不能な個別固定費まで差し引く） | 管理可能利益（管理可能な費用までを差し引く） |
| 使う場面 | 存続・撤退、投資の配分、事業の組み替え | 賞与、昇格、目標の達成度 |
| 外す数字 | 本社費・共通費の配賦額 | 管理不能な個別固定費、本社費・共通費の配賦額 |

## 計算例：2つの評価が食い違う

事業部Kの損益です（単位は千円）。

| 項目 | 予算 | 実績 |
|---|---|---|
| 売上高 | 48,000 | 50,000 |
| 変動費 | 29,000 | 30,000 |
| 限界利益 | 19,000 | 20,000 |
| 管理可能固定費（広告費、パートの人件費、消耗品など） | 8,000 | 8,000 |
| 管理可能利益 | 11,000 | 12,000 |
| 管理不能な個別固定費（本社が決めた設備の減価償却費、事業部長の給与） | 7,000 | 7,000 |
| 事業部貢献利益 | 4,000 | 5,000 |
| 本社費の配賦額 | 6,000 | 6,000 |
| 営業利益 | △2,000 | △1,000 |

| 評価 | 見る数字 | 結論 |
|---|---|---|
| 事業部長 | 管理可能利益 12,000（予算比＋1,000） | 予算を上回った。良い評価 |
| 事業部 | 事業部貢献利益 5,000 | 全社の利益に5,000貢献している。撤退すべきではない |
| 事業部 | 投下資本に対する利益率 | 設備の大きさに比べて利益が小さければ、投資の見直しを検討 |

営業利益だけを見ると「赤字の事業部の事業部長」ですが、事業部長は自分の権限の範囲で予算を超える成果を出しています。一方で、事業部としては本社が投じた設備に見合う利益を上げているかという別の問題があり、それは事業部長ではなく経営者が判断する問題です。

## 管理可能かどうかの分け方

| 費用 | 管理可能か | 理由 |
|---|---|---|
| 変動費（材料、外注、販売手数料） | 管理可能 | 仕入先の選定、値決め、受注の判断で動かせる |
| 広告宣伝費、販促費 | 管理可能 | 事業部長に予算の執行の権限がある |
| パート・アルバイトの人件費 | 管理可能 | シフトや採用を事業部長が決める |
| 本社が決めた設備投資の減価償却費 | 管理不能 | 投資の決定権が本社にある |
| 事業部長自身の給与 | 管理不能 | 事業部長が自分で決められない |
| 本社費・共通費の配賦額 | 管理不能 | 発生額も配賦基準も本社が決める |

同じ費用でも、権限の持ち方で区分は変わります。設備投資の決定権を事業部長に渡している会社なら、減価償却費は管理可能です。権限規程と区分を一致させることが、この分け方の前提です。

## 評価を賞与や昇給に結びつけるとき

管理可能利益を賞与や昇給の基準にするときは、評価の方法を賃金規程や評価規程に定め、従業員に説明します。賞与の算定方法を従業員に不利益に変える場合は、就業規則の不利益変更の問題になり、変更の合理性が求められます（労働契約法9条・10条）。

## 考え方の要点

- 「誰を評価するのか」「何を判断するのか」を先に決め、それに合う段階利益を選びます
- 事業部長の評価は管理可能利益、事業部の評価は事業部貢献利益で、本社費の配賦額はどちらにも入れません
- 管理可能かどうかは、費用の種類ではなく、決定の権限がどこにあるかで決まります

段階利益の全体の形は「[責任会計とは](/posts/responsibility-accounting/)」で扱っています。

## ひとことで言うと

> ポイント：事業部は事業部貢献利益で、事業部長は管理可能利益で評価します。事業部長が決められない設備の減価償却費や本社費を含めた数字で事業部長を評価すると、努力と結果が結びつきません。
