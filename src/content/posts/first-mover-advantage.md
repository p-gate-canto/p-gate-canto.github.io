## 結論

> 結論：先発優位は「早く始めることで築ける壁」、後発優位は「先発企業の失敗から学べる分の得」です。利用者が増えるほど価値が高まる市場や、顧客が乗り換えにくい市場では先発が、技術や顧客ニーズが読みにくい市場では後発が有利になりやすいとされます。

先発優位については、経営学者のリーバーマンとモンゴメリーが1988年の論文で体系的に整理し、同時に先発者が不利になる要因も示しました。

## 比較表

| 項目 | 先発優位 | 後発優位 |
|---|---|---|
| 意味 | 最初に市場へ参入した企業が持つ優位性 | 先発企業の動きを見てから参入する企業が持つ優位性 |
| 主な源泉 | 参入障壁の形成、早い段階での経験曲線効果、規格の主導権、早くから使う顧客の獲得、好立地や希少な資源の先取り | 先発企業の事例から学べる、市場を育てる費用を抑えられる、研究開発の費用を抑えられる、技術や顧客ニーズが定まってから参入できる |
| リスク | 市場が育たない、技術が変わる、多額の先行投資を回収できない | 先発企業に顧客や規格を押さえられる |

## 先発優位の源泉

| 源泉 | 内容 | 例 |
|---|---|---|
| 経験曲線効果 | 早く生産を始めるほど累積生産量が増え、コストで有利になる | 新しい部品の量産 |
| 規格の主導権 | 自社の規格が業界の標準（デファクトスタンダード）になる | 通信規格、決済サービス |
| 顧客の囲い込み | 最初に使った製品から乗り換えるのに手間やコストがかかる（スイッチングコスト） | 業務用ソフト、会員サービス |
| 資源の先取り | 好立地、希少な原材料、優秀な人材を先に押さえる | 駅前の店舗、特定の産地との契約 |
| 評判・ブランド | 「元祖」「最初の会社」として認知される | 新しいカテゴリーの商品 |

## 後発優位の源泉（先発者が不利になる理由）

| 源泉 | 内容 |
|---|---|
| フリーライダー効果 | 先発企業が費用をかけて育てた市場、顧客の認知、研究成果に、後から「ただ乗り」できる |
| 不確実性の解消 | 技術の方向や顧客が本当に求めるものが明らかになってから参入できる |
| 技術の進歩 | 先発企業が古い技術に投資している間に、新しい技術で参入できる |
| 先発企業の慣性 | 先発企業が既存の設備や組織にしばられ、変化への対応が遅れる |

## どちらを選ぶかの判断軸

| 状況 | 有利になりやすい方 |
|---|---|
| 利用者が増えるほど価値が高まる（ネットワーク外部性が強い） | 先発 |
| 顧客が乗り換えにくい（スイッチングコストが高い） | 先発 |
| 立地や資源の数に限りがある | 先発 |
| 技術や顧客ニーズの変化が速く、正解が見えない | 後発 |
| 市場を育てるのに大きな費用がかかる | 後発 |
| 自社に、先発企業より優れた技術・販売力・資金力がある | 後発 |

## 中小企業での使い方

| 戦い方 | 内容 | 例 |
|---|---|---|
| 後発＋集中 | 大手が切り開いた市場に、特定の顧客層に絞って後から参入する | 大手のサブスク型サービスが広まった後に、特定業種向けに特化したサービスを始める |
| 地域での先発 | 全国では後発でも、自分の地域では最初に始める | 市内で初めて、補助金を使った省エネ改修の専門窓口を開く |
| 先発の利益を早く回収 | 先発するなら、大手が参入する前に投資を回収できる計画にする | 小さく始めて、早期に黒字化する |

> ポイント：経営資源の限られた中小企業にとって、市場を一から育てる先発は負担が大きくなりがちです。「後発＋集中」か「地域での先発」が現実的な選択肢になります。

## 試験対策のポイント

先発優位の源泉として挙がるのは、経験曲線効果、規格の主導権、顧客のスイッチングコスト、希少な資源の先取りです。後発優位の源泉は、先発企業の投資にただ乗りできるフリーライダー効果、市場の不確実性が解消されていること、技術の進歩の3つ。どちらの源泉かを入れ替えた選択肢がよく出ます。

もう1つの論点が、ネットワーク外部性との関係です。利用者が増えるほど価値が上がる市場では、規格を先に押さえた企業が大きく勝ちやすく、先発が有利になります。

## よくある誤解

「早い者勝ち」とは限りません。市場が育つ前に資金が尽きてしまう先発企業は少なくなく、先に出たことがそのまま勝因になるわけではないのです。

後発は先発をまねするだけ、という見方も正確ではありません。成功する後発企業は、先発企業の失敗から学び、よりよい製品や売り方を用意して参入しています。
