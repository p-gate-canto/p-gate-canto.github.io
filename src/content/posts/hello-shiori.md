## しおりをはさむ、という感覚で

本を読んでいる途中で手を止めるとき、しおりをはさみます。あとで戻ってきたときに、どこまで進んだか、何を考えていたかを思い出すためです。

税理士・会社役員として働きながら資格の勉強を続けていると、「これは覚えておきたい」と思う瞬間がたくさんあります。その瞬間を書き留め、しおりをはさんでいきます。

## 書くこと

このブログは、3つの柱とツールでできています。

| 柱 | 中身 |
|---|---|
| 仕事 | 経営・財務・税務・人事・DXなど、9分野の実務の論点 |
| 学び | 資格の勉強法、学習計画、記憶とアウトプット |
| 自己管理 | 時間管理、習慣、体調、仕事術、考え方 |
| ツール | 実務と勉強で使っている自作ツール |

### 仕事の9分野

| 分野 | 中身 |
|---|---|
| 経営戦略 | 理念・ビジョン、経営計画、企業戦略、競争戦略、機能別戦略 |
| 財務・会計戦略 | 資金調達、資金繰り、管理会計、投資判断 |
| 税務戦略 | 法人税、所得税、消費税、相続税・贈与税 |
| 事業開発戦略 | 新規事業、ビジネスモデル、価格戦略 |
| M&A・組織再編戦略 | スキーム検討、デューデリジェンス、企業価値評価 |
| マーケティング・営業戦略 | 市場・顧客分析、集客、営業の仕組み |
| 組織・人事戦略 | 評価・賃金制度、採用、労務管理 |
| DX・IT・AI戦略 | 業務自動化、AI活用、データ活用 |
| リスク・ガバナンス戦略 | 内部統制、コンプライアンス、BCP |

## 書き方のルール

1. 結論から書く
2. 制度の話には、根拠となる条文・通達と、いつの時点の法令かを添える
3. 専門用語は使ったうえで、ふだんの言葉に言い換える

数字の外側にあることを、ゆっくり考えていく場所にするつもりです。
