## 結論

> 結論：組織論は「仕事の効率」を重視した古典的管理論から、「人間関係」を重視した人間関係論、組織を「人の協働の仕組み」と捉えた近代的組織論、そして「最適な組織は環境しだい」とするコンティンジェンシー理論へと発展しました。

前の理論の限界を、次の理論が補う流れになっています。順番で覚えると、それぞれの主張と批判がつながり、試験でも実務でも使いやすくなります。

## 組織論の全体像

| 時期の目安 | 区分 | 代表的な理論と人物 | 一言でいうと |
|---|---|---|---|
| 1910年代〜 | 古典的管理論 | 科学的管理法（テイラー）、管理過程論（ファヨール）、官僚制組織論（ウェーバー） | 効率よく働く仕組み |
| 1920〜30年代 | 人間関係論 | ホーソン実験（メイヨー、レスリスバーガー） | 人の気持ちと人間関係 |
| 1930年代後半〜 | 近代的組織論 | 協働体系論（バーナード）、意思決定論（サイモン） | 人が協働する仕組み |
| 1960年代〜 | コンティンジェンシー理論 | バーンズとストーカー、ローレンスとローシュ、ウッドワード | 環境に合った組織 |

## 1. 古典的管理論

### 科学的管理法（テイラー）

フレデリック・テイラーは、勘と経験に頼っていた工場の作業を、科学的に管理しようとしました。

- **時間研究・動作研究**：作業を細かく分けて時間を測り、最も効率のよいやり方を決める
- **課業（タスク）管理**：1日に達成すべき標準の作業量を決める
- **差別出来高給制度**：標準の作業量を達成した人には高い賃率、達成しない人には低い賃率を適用する
- **職能別職長制**：1人の職長がすべてを見るのではなく、計画・指導などの機能ごとに職長を分ける

> 注意：テイラーの方法は生産性を大きく高めましたが、人間を機械の部品のように扱うとの批判を受けました。この批判が、人間関係論が生まれるきっかけになります。

### 管理過程論（ファヨール）

アンリ・ファヨールは、企業の活動を6つに分けました。

| 6つの活動 | 内容 |
|---|---|
| 技術活動 | 生産・製造 |
| 商業活動 | 購買・販売 |
| 財務活動 | 資金の調達と運用 |
| 保全活動 | 財産と従業員の保護 |
| 会計活動 | 記録・原価計算 |
| 管理活動 | 予測・組織・命令・調整・統制 |

このうち管理活動を、**予測 → 組織 → 命令 → 調整 → 統制**の5つの要素が循環する過程として捉えました。今日のPDCAサイクルの源流といえる考え方です。

### ファヨールの14の管理原則

1. 分業
2. 権限と責任
3. 規律
4. 命令の一元性
5. 指揮の一元性
6. 個人の利益の全体の利益への従属
7. 報酬
8. 集権化
9. 階層組織
10. 秩序
11. 公正
12. 従業員の安定
13. 創意（イニシアチブ）
14. 団結

> 補足：サイモンは、これらの管理原則を「互いに矛盾することもある経験則（格言）にすぎない」と批判しました。たとえば「専門化を進めよ」と「統制範囲を狭くせよ」は、同時に満たすのが難しい場合があります。

### 官僚制組織論（ウェーバー）

マックス・ウェーバーは、規則と階層にもとづく「官僚制」が、最も正確で効率的な組織の形だと考えました。

| 官僚制の主な特徴 | 内容 |
|---|---|
| 規則による支配 | 仕事は明文化された規則にもとづいて行う |
| 権限の階層 | 上下関係がはっきりしている |
| 文書主義 | 決定や記録を文書に残す |
| 専門化 | 専門の知識を持つ人が職務を担う |
| 没人格性 | 個人的な感情を持ち込まず、公平に処理する |

その後、ロバート・マートンは、規則を守ること自体が目的になり、かえって非効率になる現象を「**官僚制の逆機能**」と呼びました。

## 2. 人間関係論（メイヨー、レスリスバーガー）

ウェスタン・エレクトリック社のホーソン工場で行われた一連の実験（ホーソン実験）では、照明の明るさなどの作業条件よりも、職場の人間関係や、注目されているという意識のほうが生産性に影響することが分かりました。

- **非公式組織の発見**：会社が決めた公式の組織とは別に、従業員どうしの自然なグループ（非公式組織）があり、その規範が働き方に強く影響する
- **社会人モデル**：人は経済的な報酬だけでなく、仲間との関係や承認を求めて働く

## 3. 近代的組織論

### バーナードの協働体系論

チェスター・バーナードは、著書『経営者の役割』（1938年）で、組織を「2人以上の人々の、意識的に調整された活動や力の体系」と定義しました。

| 組織が成立する3要素 | 内容 |
|---|---|
| 共通目的 | メンバーが共有する目的 |
| 貢献意欲 | 目的のために協力しようとする意思 |
| コミュニケーション | 目的と意欲をつなぐ情報の伝達 |

組織が存続するための条件も示しています。

| 存続の条件 | 内容 |
|---|---|
| 有効性 | 組織の目的を達成できているか |
| 能率 | メンバー一人ひとりが満足し、貢献を続けようと思えるか |
| 組織均衡 | 組織がメンバーに与える「誘因」が、メンバーが提供する「貢献」と同じかそれ以上であること |

> ポイント：バーナードは、命令が権限を持つかどうかは、受け手がそれを受け入れるかどうかで決まると考えました（**権限受容説**）。「社長が言ったから」ではなく「納得したから」動く、という今日のマネジメントにも通じる考え方です。

### サイモンの意思決定論

ハーバート・サイモンは、バーナードの考え方を受け継ぎ、組織を「意思決定のシステム」として捉えました。人の合理性には限界がある（限定合理性）ため、組織は役割分担やルールでその限界を補う仕組みだと考えました。詳しくは「[サイモンの意思決定プロセスとアンゾフの意思決定の3分類](/posts/decision-making-simon-ansoff/)」で整理しています。

## 4. コンティンジェンシー理論（条件適合理論）

「どんな場合にも最適な組織の形はない。最適な組織は、環境や技術によって変わる」という考え方です。

| 研究者 | 主な発見 |
|---|---|
| バーンズとストーカー | 安定した環境では、規則と階層を重んじる「機械的組織」が、変化の激しい環境では、柔軟で横のつながりが強い「有機的組織」が適している |
| ローレンスとローシュ | 環境が不確実なほど、部門ごとの違い（分化）が大きくなり、それをまとめる仕組み（統合）が重要になる |
| ウッドワード | 生産技術（個別生産・大量生産・装置生産）によって、適した組織構造が違う |

## 組織設計の5原則

| 原則 | 内容 |
|---|---|
| 専門化の原則 | 仕事を分け、同じ種類の仕事に専念させて効率を上げる |
| 権限・責任一致の原則 | 与える権限と負わせる責任の大きさをそろえる |
| 統制範囲の原則（スパン・オブ・コントロール） | 1人の上司が管理できる部下の数には限りがある |
| 命令一元化の原則 | 部下は1人の上司からだけ命令を受ける |
| 例外の原則（権限委譲） | 日常的な判断は部下に任せ、上司は例外的な判断に集中する |

## 組織文化の形成要因

組織文化は、組織の中で共有される価値観や行動のしかたです。次のような条件で形づくられ、強まります。

- **近接性**：物理的に近くで働いている
- **同質性**：考え方や特性が似ている
- **相互依存性**：仕事で影響を与え合い、支え合っている
- **コミュニケーション・ネットワーク**：情報が全体に行き渡っている
- **帰属意識を高める機会**：研修や行事などがある

## 実務での使い方

| 場面 | 使える理論 | 打ち手の例 |
|---|---|---|
| 社長が全員に直接指示を出していて回らない | 統制範囲・命令一元化・例外の原則 | 5〜8人ごとにリーダーを置き、日常の判断を任せる |
| マニュアルが増えて現場が動かなくなった | 官僚制の逆機能 | ルールの目的を書き添え、目的に合わないルールを廃止する |
| 給与を上げても定着しない | 人間関係論、バーナードの組織均衡 | 承認や成長の機会など、お金以外の「誘因」を増やす |
| 新規事業部門が既存部門のルールに縛られる | コンティンジェンシー理論 | 新規事業だけは有機的な組織として、ルールを分ける |

> ポイント：中小企業では、従業員が10人を超えるあたりから社長1人では目が届かなくなる、とよく言われます。統制範囲の原則を意識して、指示系統を見直すタイミングの目安になります。

## 試験対策のポイント

- **人物と理論の組み合わせ**：テイラー＝科学的管理法、ファヨール＝管理過程論、ウェーバー＝官僚制、メイヨー＝ホーソン実験、バーナード＝協働体系・組織の3要素。
- **バーナードの有効性と能率**：有効性は「組織の目的の達成度」、能率は「個人の満足度」。一般的な意味の「能率（効率）」と違う点がひっかけになります。
- **官僚制の逆機能**：指摘したのはマートン。ウェーバー自身ではありません。
- **機械的組織と有機的組織**：安定した環境には機械的、変化の激しい環境には有機的。

人名と理論の組み合わせは、人名を単独で覚えようとすると抜けていきます。私がすすめたいのは、「歴史的背景 → 人名 → 理論 → 代表的なキーワード」の4点をセットにして覚える方法です。

たとえばテイラーなら、「19世紀末のアメリカで、工場の組織的怠業が問題になっていた → テイラー → 科学的管理法 → 課業管理・差別出来高給制度」。メイヨーなら、「照明や休憩などの作業条件だけでは生産性の変化を説明できなかった → メイヨー、レスリスバーガー → 人間関係論 → インフォーマル組織・モラール」。背景から入ると、理論が生まれた理由ごと記憶に残ります。

## よくある誤解

1. **「科学的管理法は古い考え方で、今は使えない」**：作業の標準化や時間の測定は、今日の業務改善やマニュアルづくりの基礎として生きています。
2. **「人間関係論は、仲良くすれば生産性が上がるという理論」**：非公式組織の規範しだいでは、生産性を下げる方向にも働くことが示されています。
