## 結論

> 結論：中小企業のM&Aで最も多いのは、株主が株式を売る「株式譲渡」です。会社をそのまま引き継ぐか（株式譲渡・合併・株式交換）、事業だけを切り出すか（事業譲渡・会社分割）で、手法が大きく分かれます。手法によって税金のかかり方と手続きの重さが大きく違うため、最初に比較することが大切です。

## 法的な手法

| 手法 | 内容 | 引き継ぎ方 |
|---|---|---|
| 株式譲渡 | 株主が保有する株式を買い手に売り、会社の支配権を移す | 会社ごと（会社の権利義務はそのまま） |
| 事業譲渡 | 事業に関する資産・負債・契約を、1つずつ特定して移す | 個別に移す（契約の相手方の同意などが必要） |
| 吸収合併 | 消える会社の権利義務の全部を、存続する会社が引き継ぐ | 包括的に引き継ぐ |
| 新設合併 | 複数の会社が消え、新しく設立する会社が引き継ぐ | 包括的に引き継ぐ |
| 吸収分割 | 事業に関する権利義務を、既存の会社に引き継がせる | 包括的に引き継ぐ |
| 新設分割 | 事業に関する権利義務を、新しく設立する会社に引き継がせる | 包括的に引き継ぐ |
| 株式交換 | 既存の会社が、他社の発行済株式の全部を取得して完全親会社になる | 100%子会社にする |
| 株式移転 | 新しく設立する会社が、既存の会社の発行済株式の全部を取得する（持株会社化） | 100%子会社にする |
| 株式交付 | 自社の株式を対価にして、他社を子会社（50%超）にする。100%でなくてもよい | 子会社にする |
| 第三者割当増資 | 特定の相手に新株を発行し、議決権を持たせる | 出資を受け入れる |

> 補足：会社分割は、分割の対価（承継する会社の株式）を誰が受け取るかで、「分社型分割」（分割する会社が受け取る）と「分割型分割」（分割する会社の株主が受け取る）に分かれます。

## 株式譲渡と事業譲渡の比較

中小企業のM&Aで特に比べられることが多い2つの手法です。

| 項目 | 株式譲渡 | 事業譲渡 |
|---|---|---|
| 売り手 | 株主（個人のオーナーなど） | 会社 |
| 対価を受け取る人 | 株主 | 会社 |
| 売り手の税金（個人株主の場合） | 株式の譲渡所得として、所得税・住民税（復興特別所得税を含めて20.315%）の申告分離課税 | 会社の譲渡益に法人税等がかかる。オーナーが受け取るには、さらに役員退職金や配当などが必要 |
| 消費税 | かからない | 課税資産（建物・設備・のれんなど）の部分にかかる |
| 許認可 | 会社に残るので、原則としてそのまま | 原則として引き継げず、取り直しが必要なものが多い |
| 契約・従業員 | そのまま会社に残る | 個別に移す。従業員の同意が必要 |
| 簿外債務のリスク（買い手） | 引き継ぐおそれがある | 引き継ぐ範囲を選べるので、リスクを抑えやすい |

> 注意：株式譲渡の譲渡所得の税率は、非上場株式の場合、所得税15%・復興特別所得税0.315%・住民税5%の合計20.315%です（2026年時点）。所得が極めて高い場合は、追加の課税措置（「極めて高い水準の所得に対する負担の適正化措置」、いわゆるミニマムタックス）の対象になることがあります。個別の試算は、必ず税理士と確認してください。

## 資金調達と買い手の種類

| 用語 | 内容 |
|---|---|
| LBO | 買収する会社の資産や将来のキャッシュフローを返済の原資にして、借入金で買収する |
| MBO | 経営陣が買い手となって、自社の株式を取得する |
| EBO | 従業員が買い手となって、自社の株式を取得する |
| MBI | 外部の経営者が、投資家の支援を受けて会社を買収し、経営者になる |
| SPC（受け皿会社） | 買収のためだけに設立する会社。LBOやMBOで使う |
| デットプッシュダウン | SPCの買収借入を、合併などで買収された会社の側に移す |
| PEファンド | 未上場企業に投資し、企業価値を高めて売却益を狙う投資ファンド |
| サーチファンド | 経営者候補が投資家の資金で買収先を探し、買収後に自ら経営する仕組み |
| アーンアウト | 買収後の業績の達成度に応じて、対価の一部を後から支払う条項 |

## 売り手側の切り出しと少数株主の整理

| 用語 | 内容 |
|---|---|
| カーブアウト | 事業部門や子会社を切り出して、外部に売却する |
| スピンオフ | 子会社の株式を親会社の株主に分配して、独立させる（税務上は「株式分配」） |
| スプリットオフ | 親会社の株式と引き換えに、子会社の株式を一部の株主に交付して分離する |
| スクイーズアウト | 少数株主を、金銭を対価に締め出して完全子会社にする |
| 株式併合 | 複数の株式を1株にまとめる。スクイーズアウトの手段として使われる |
| 特別支配株主の株式等売渡請求 | 議決権の90%以上を持つ株主が、残りの株式を強制的に取得できる制度（会社法179条） |
| 全部取得条項付種類株式 | 株主総会の決議で、会社がその全部を取得できる種類株式 |

## 取引の流れ

| 用語 | 内容 |
|---|---|
| 1. NDA（秘密保持契約） | 検討段階で開示する情報を、外に漏らさないと約束する |
| 2. LOI・MOU（基本合意書） | 主な条件と、独占的に交渉する権利を定める |
| 3. DD（デューデリジェンス） | 買い手が、財務・税務・法務・労務などを調べる |
| 4. SPA（株式譲渡契約） | 最終的な契約書を結ぶ。表明保証などを定める |
| 5. クロージング | 対価を支払い、株式や事業を引き渡す |
| 6. PMI | 買収後に、経営・業務・人事・システムを統合する |

### 価値の算定に関する用語

| 用語 | 内容 |
|---|---|
| EV（企業価値） | 株式価値に純有利子負債を加えた、事業全体の価値 |
| のれん | 買収価格のうち、受け入れた純資産の時価を超える部分 |
| 資産調整勘定 | 非適格の組織再編や事業譲渡で生じる、税務上ののれん。5年（60か月）で均等に償却する |
| 表明保証 | 契約時点での事実関係を真実と保証し、違反があれば補償する条項 |

## 中小企業のM&Aで押さえたい公的なルールと支援

| 項目 | 内容 |
|---|---|
| 中小M&Aガイドライン | 中小企業庁が策定した、中小M&Aの手続きや支援機関の行動指針。2024年8月に第3版に改訂され、仲介者・FAの手数料や担当者の経験の説明、広告・営業の禁止事項などが拡充された |
| M&A支援機関登録制度 | 中小企業庁が2021年に創設。中小M&Aガイドラインの遵守を宣言した仲介者・FAが登録される。登録された支援機関への費用は、事業承継・M&A関係の補助金の対象になりうる |
| 中小企業事業再編投資損失準備金 | 中小企業がM&Aで株式を取得したとき、取得価額の一定割合（経営力向上計画の場合は70%、特別事業再編計画の場合は最大100%）を準備金として損金に算入できる制度 |

> 注意：中小企業事業再編投資損失準備金の拡充分（特別事業再編計画）は、2027年3月31日までに計画の認定を受けたM&Aが対象です。適用期限や要件は改正が多いため、実行前に最新の要件を確認してください。

## 試験対策のポイント

- **包括承継と個別承継**：合併・会社分割は包括承継、事業譲渡は個別承継（契約ごとに相手方の同意が必要）。
- **株式交換と株式移転**：株式交換は既存の会社が親会社に、株式移転は新しく設立する会社が親会社になる。
- **株式交付**：50%超の子会社化に使える。100%でなくてもよい。
- **LBO・MBO・EBO・MBIの区別**：買い手が誰か、資金をどう調達するか。

## ひとことで言うと

> ポイント：会社ごと渡すなら株式譲渡、事業だけ渡すなら事業譲渡か会社分割が基本です。手法を選ぶ前に、税金と契約の引き継ぎを比較しましょう。
