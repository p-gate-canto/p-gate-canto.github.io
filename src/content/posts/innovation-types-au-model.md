## 結論

> 結論：イノベーションは「何を変えるか（製品か工程か）」「どれだけ変えるか（改良か刷新か）」「誰と変えるか（自社だけか外部とか）」「誰の市場を変えるか（既存顧客か新しい顧客か）」の4つの軸で分類できます。

イノベーションは「技術革新」と訳されることが多いですが、本来は技術に限らず、新しい価値を生み出して社会に広めること全般を指します。

## シュンペーターの「新結合」

経済学者のシュンペーターは、イノベーションを、既存の要素の新しい組み合わせ（新結合）として捉え、次の5つを挙げました。

| 新結合の種類 | 中小企業での例 |
|---|---|
| 新しい財（製品・サービス）の生産 | 地元の果物を使った新しい加工品 |
| 新しい生産方法の導入 | ロボットによる自動化、ICT施工 |
| 新しい販路の開拓 | ネット通販、海外への輸出 |
| 新しい原材料・供給源の獲得 | 未利用の地域資源の活用 |
| 新しい組織の実現 | 同業者との共同出資会社、分社化 |

> ポイント：技術がなくても、販路や組み合わせを変えるだけで立派なイノベーションです。中小企業の新事業は、この5つのどれかに当てはまるかで整理すると、補助金の申請書でも説明しやすくなります。

## イノベーションの分類

| 軸 | 分類 | 内容 |
|---|---|---|
| 何を変えるか | プロダクト・イノベーション | 新しい製品・サービスで価値を生む |
| | プロセス・イノベーション | 生産工程や作り方を変えて価値を生む |
| どれだけ変えるか | インクリメンタル・イノベーション | 改良を積み重ねる、漸進的な革新 |
| | ラディカル・イノベーション | 従来と全く異なる、抜本的な革新 |
| 誰と変えるか | クローズド・イノベーション | 研究開発から製品化まで、自社の中だけで完結させる |
| | オープン・イノベーション | 社外の技術やアイデアを組み合わせ、自社の技術も社外で生かす（チェスブロウが2003年に提唱） |
| 誰の市場を変えるか | 持続的イノベーション | 既存の顧客が求める性能を高めていく |
| | 破壊的イノベーション | 性能は劣っても安く・手軽な製品で、新しい顧客や低価格帯から市場を塗り替える |
| その他 | リバース・イノベーション | 新興国で生まれた製品や技術を、先進国に展開する |

## イノベーションのジレンマ

経営学者のクリステンセンは、1997年の著書『イノベーションのジレンマ』で、優良企業ほど破壊的イノベーションに負けやすいことを示しました。

1. 業界のリーダー企業は、主要な顧客の声を聞き、既存製品の性能を高める（持続的イノベーション）
2. その結果、製品の性能が多くの顧客の求める水準を超えてしまう
3. その間に、性能は劣るが安くて手軽な新製品（破壊的イノベーション）が、小さな市場から広がる
4. 新製品の性能が十分に上がったころには、リーダー企業は対応できなくなっている

> ポイント：これは中小企業にとってはチャンスでもあります。大手が「小さすぎて採算に合わない」と相手にしない市場は、破壊的イノベーションの入口になり得ます。

## 製品アーキテクチャ

製品アーキテクチャは、製品をどんな部品の組み合わせとして設計するかという基本的な考え方です。日本では、藤本隆宏氏の研究で広く知られるようになりました。

| 分類 | 内容 | 長所 | 課題 | 例 |
|---|---|---|---|---|
| モジュール型（組み合わせ型） | 機能ごとに独立した部品を組み合わせる | 開発が速い、部品を交換しやすい | まねされやすく、価格競争（コモディティ化）に陥りやすい | パソコン |
| インテグラル型（すり合わせ型） | 部品どうしを相互に調整して、全体で機能をつくる | まねされにくい | 部品間の調整に手間がかかる | 自動車 |
| オープン型 | 部品の接続ルールを公開し、企業を超えた業界標準にする | 市場が広がりやすい | コモディティ化しやすい | パソコンの周辺機器 |
| クローズ型 | 接続ルールを社内や関連会社だけに限る | 独自性を保ちやすい | 市場が広がりにくい | 専用の部品で作る機械 |

> 補足：日本のものづくり企業は、部品どうしの細かな調整（すり合わせ）を得意とし、インテグラル型の製品で強みを発揮してきたとされます。

## A-Uモデル

アバナシーとアッターバックが示した、産業の発展段階とイノベーションの関係です。

| 段階 | 状況 | 中心となるイノベーション |
|---|---|---|
| 流動期 | 製品の形が定まらず、さまざまな試みが出る | ラディカルなプロダクト・イノベーション |
| 移行期 | 業界の標準となる設計（ドミナント・デザイン）が現れる | プロダクトからプロセスへ重心が移る |
| 固定期 | 製品が成熟し、効率が競争の中心になる | インクリメンタルなプロセス・イノベーション |

> 補足：固定期に入り、効率を追求するあまり新しいイノベーションが生まれにくくなる状態を「生産性のジレンマ」といいます。

## 技術S字カーブと技術の不連続性

技術の性能は、はじめは知識が足りないためゆっくり伸び、知識がたまると急速に伸び、やがて限界に近づいて再び伸びが鈍ります。この形をS字カーブといいます。古い技術のS字カーブの限界を、新しい技術のS字カーブが乗り越えることを「技術の不連続性」といいます。

## 中小企業での使い方

| 場面 | 使える考え方 | 打ち手の例 |
|---|---|---|
| 新製品の開発 | オープン・イノベーション | 大学や公設試験研究機関と共同研究をする |
| 価格競争に巻き込まれている | 製品アーキテクチャ | 部品を組み合わせるだけの製品から、すり合わせが必要な製品に重心を移す |
| 大手が手を出さない市場を見つけた | 破壊的イノベーション | 小さな市場で「安くて十分」な製品を出し、少しずつ性能を上げる |
| 自社の業界が成熟している | A-Uモデル | 製品の改良より、工程の改善（プロセス・イノベーション）でコストを下げる |

## 試験対策のポイント

- **A-Uモデルの順番**：流動期（プロダクト中心）→ 移行期（ドミナント・デザイン）→ 固定期（プロセス中心）。
- **持続的と破壊的**：イノベーションのジレンマはクリステンセン。破壊的イノベーションは「当初は性能が低い」点がポイントです。
- **モジュール型の弱点**：コモディティ化しやすい。
- **オープン・イノベーションの提唱者**：チェスブロウ。

## よくある誤解

1. **「イノベーション＝最先端の技術」**：販路や組織の新しい組み合わせもイノベーションです。
2. **「破壊的イノベーション＝すごい新技術」**：最初は既存製品より性能が劣ることが多いのが特徴です。
