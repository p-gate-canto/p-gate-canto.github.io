## 結論

> 結論：イノベーションは「何を変えるか（製品か工程か）」「どれだけ変えるか（改良か刷新か）」「誰と変えるか（自社だけか外部とか）」の3つの軸で分類できます。

## イノベーションの分類

| 軸 | 分類 | 内容 |
|---|---|---|
| 何を変えるか | プロダクト・イノベーション | 新しい製品・サービスで価値を生む |
| | プロセス・イノベーション | 生産工程や作り方を変えて価値を生む |
| どれだけ変えるか | インクリメンタル・イノベーション | 改良を積み重ねる、漸進的な革新 |
| | ラディカル・イノベーション | 従来と全く異なる、抜本的な革新 |
| 誰と変えるか | クローズド・イノベーション | 自社の中だけで完結させる |
| | オープン・イノベーション | 社外の技術やアイデアを組み合わせる |
| その他 | リバース・イノベーション | 新興国で生まれた製品や技術を、先進国に展開する |

## 製品アーキテクチャ

製品アーキテクチャは、製品をどんな部品の組み合わせとして設計するかという基本的な考え方です。

| 分類 | 内容 | 長所 | 課題 |
|---|---|---|---|
| モジュール型 | 機能ごとに独立した部品を組み合わせる | 開発が速い、部品を交換しやすい | まねされやすく、価格競争（コモディティ化）に陥りやすい |
| インテグラル型 | 部品どうしを相互に調整して、全体で機能をつくる | まねされにくい | 部品間の調整に手間がかかる |
| オープン型 | 部品の接続ルールを公開し、業界の標準にする | 市場が広がりやすい | コモディティ化しやすい |
| クローズ型 | 接続ルールを社内や関連会社だけに限る | 独自性を保ちやすい | 市場が広がりにくい |

## A-Uモデル

アバナシーとアッターバックが示した、産業の発展段階とイノベーションの関係です。

| 段階 | 状況 | 中心となるイノベーション |
|---|---|---|
| 流動期 | 製品の形が定まらず、さまざまな試みが出る | ラディカルなプロダクト・イノベーション |
| 移行期 | 業界の標準となる設計（ドミナント・デザイン）が現れる | プロダクトからプロセスへ移る |
| 固定期 | 製品が成熟し、効率が競争の中心になる | インクリメンタルなプロセス・イノベーション |

## 技術S字カーブと技術の不連続性

技術の性能は、はじめは知識が足りないためゆっくり伸び、知識がたまると急速に伸び、やがて限界に近づいて再び伸びが鈍ります。この形をS字カーブといいます。古い技術のS字カーブの限界を、新しい技術のS字カーブが乗り越えることを「技術の不連続性」といいます。

> ポイント：業界のリーダー企業が、既存製品の改良に集中するあまり新しい技術への対応が遅れる現象は「イノベーションのジレンマ」（クリステンセン）と呼ばれます。

## ひとことで言うと

> ポイント：産業の初期は「製品の革新」、成熟すると「作り方の改良」が競争の中心になります。自社の業界がどの段階にあるかで、投資の重点を変えましょう。
