## 結論

> 結論：買収防衛策は、「味方を増やす」「買収者の持分を薄める」「会社の魅力を下げる」「買収のルールを示す」の4つに分けると整理しやすくなります。なお、経済産業省の「企業買収における行動指針」（2023年8月）以降、敵対的買収は「同意なき買収」と呼ばれることが増えています。

## 友好的買収と敵対的買収

| 用語 | 内容 |
|---|---|
| 友好的買収 | 対象会社の取締役会の賛同を得て行う買収 |
| 敵対的買収（同意なき買収） | 取締役会の賛同を得ずに行う買収 |
| TOB（公開買付け） | 価格・期間・株数を公告し、不特定多数の株主から株式を買い集める |
| ベアハグ | 公開の書簡などで買収提案を突きつけ、取締役会に圧力をかける |
| プロキシーファイト（委任状争奪戦） | 株主総会の委任状を集めて、経営権を争う |
| 忍び寄り（クリーピング） | 市場で少しずつ株式を買い増し、支配権に近づく |
| グリーンメーラー | 株式を買い集め、対象会社などに高値で買い取らせることを狙う者 |

## 2026年5月施行：公開買付制度の改正

2024年5月に公布された改正金融商品取引法により、公開買付制度が大きく見直され、2026年5月1日から適用されています。

| 項目 | 改正前 | 改正後 |
|---|---|---|
| 公開買付けが義務になる割合 | 議決権の3分の1超 | 議決権の30%超 |
| 市場内取引（立会内） | 原則として規制の対象外 | 30%を超える場合は原則として対象 |
| 急速な買付けの規制 | あり | 廃止 |

市場で少しずつ株式を買い集めて支配権を得る「忍び寄り」が、以前より難しくなりました（[大和総研「令和6年金商法等改正法 公開買付制度の改正内容の詳細」](https://www.dir.co.jp/report/research/law-research/securities/20250715_025206.html)）。

## 買収防衛策

| 分類 | 用語 | 内容 |
|---|---|---|
| 味方を増やす | ホワイトナイト | 敵対的な買収者に対抗して、友好的に買収や出資をしてくれる第三者 |
| | ホワイトスクワイア | 支配権までは取らず、友好的な安定株主として一部の株式を引き受ける第三者 |
| | 株式の持ち合い・安定株主工作 | 取引先や従業員持株会など、友好的な株主の比率を高める |
| 持分を薄める・コストを上げる | ポイズンピル（ライツプラン） | 買収者が一定割合を取得した時点で、買収者以外の株主に新株を発行し、買収者の持分を薄める |
| | 第三者割当（防衛目的） | 友好的な相手に新株を発行する。主要目的ルールにより差し止められることがある |
| | 自社株買い・増配 | 株価を上げ、買収にかかる費用を増やす |
| 会社の魅力を下げる | 焦土作戦（クラウンジュエル） | 主要な資産や事業を売却し、買収する意味をなくす |
| | ゴールデンパラシュート | 買収で解任された役員に、巨額の退職金を支払う契約 |
| | ティン・パラシュート | 買収時に、一般の従業員に割増の退職金を支払う取り決め |
| 支配の仕組み | 黄金株（拒否権付種類株式） | 合併などの重要な議案に拒否権を持つ種類株式 |
| | スタッガード・ボード（期差任期制） | 取締役の改選時期をずらし、一度に過半数を入れ替えられなくする。日本では取締役の任期が原則2年以内のため、効果は限られる |
| 逆に攻める | パックマン・ディフェンス | 買収者に対して、逆に買収を仕掛ける |
| ルールを示す | 事前警告型防衛策 | 情報提供などのルールを事前に公表し、守られなければ対抗措置をとると示しておく |
| | 有事導入型防衛策 | 買収提案が出た後に導入する防衛策 |

## 公正さを確保するための用語

| 用語 | 内容 |
|---|---|
| 主要目的ルール | 経営陣の支配権を守ることが主な目的の新株発行は、不公正な発行として差し止められるという、裁判上の判断の枠組み |
| MoM（マジョリティ・オブ・マイノリティ） | 買収者と利害関係のない株主の過半数の賛成を、取引成立の条件にする |
| 特別委員会 | MBOなど利益が相反する取引で、独立した立場から取引条件を検討する委員会 |
| フェアネス・オピニオン | 第三者の算定機関が、買収価格の公正さについて示す意見書 |

## 代表的な裁判例

| 事件 | 年 | ポイント |
|---|---|---|
| ニッポン放送事件 | 2005年 | 経営支配権の維持を主な目的とする新株予約権の発行が、不公正発行として差し止められた。主要目的ルールの代表例 |
| ブルドックソース事件 | 2007年 | 株主総会の特別決議を経た買収防衛策（新株予約権の無償割当て）について、最高裁が株主の判断を尊重して適法とした |

## 経済産業省「企業買収における行動指針」

2023年8月に公表された指針で、上場会社の買収について、次の3つの原則を示しています。

1. **企業価値・株主共同の利益の原則**：望ましい買収かどうかは、企業価値と株主全体の利益を高めるかで判断する
2. **株主意思の原則**：会社の経営支配権に関する事項は、株主の合理的な意思にもとづくべきである
3. **透明性の原則**：株主の判断のために、有用かつ適切な情報が提供されるべきである

## 中小企業への示唆

中小企業では、株式の大半をオーナー家が持っているため、敵対的買収が問題になることはほとんどありません。むしろ注意すべきなのは、次のような「内側からの支配権の問題」です。

| リスク | 対策の例 |
|---|---|
| 相続で株式が親族に分散し、議決権がまとまらない | 遺言、生前贈与、種類株式（議決権制限株式）の活用 |
| 経営に関わらない株主から、高値での買い取りを求められる | 定款に株式の譲渡制限を設ける、相続人等に対する売渡請求の規定を設ける |
| 後継者に議決権が集まらない | 黄金株（拒否権付種類株式）を先代が持ちながら、段階的に株式を移す |

> ポイント：「黄金株」や「売渡請求」は、上場企業の防衛策というより、中小企業の事業承継で使われることの多い仕組みです。導入するには定款の変更が必要なため、司法書士や税理士と相談しながら進めます。

## 試験対策のポイント

用語の数が多い分野ですが、問われ方には型があります。ホワイトナイトとホワイトスクワイアの違いは「支配権まで取るか、一部の株式を持つにとどまるか」。ポイズンピルは、買収者以外の株主に新株を発行して、買収者の持分を薄める仕組みです。

裁判の考え方では、支配権を維持することが主な目的の新株発行は差し止められうる、という主要目的ルールが基本になります。経済産業省の行動指針については、企業価値・株主共同の利益、株主意思、透明性の3原則を名前で言えるようにしておきたいところです。
