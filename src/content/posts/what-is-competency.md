## 結論

> 結論：コンピテンシーとは、高い成果を上げる人に共通して見られる行動の特性です。知能や学歴ではなく「実際にどう動いたか」で人を見るために生まれた考え方で、日本では、能力考課の基準だった職務遂行能力に代わるものとして広がりました。
>
> 分け方は大きく5つあります。見えやすさの層、役割（最低限か、差がつくか）、中身の領域、使う範囲（全社・職種・階層）、教育や社会での広がりです。自社で使うときは、この地図のどこを使っているのかを意識すると、項目がぶれません。

## コンピテンシーの意味

コンピテンシーは、英語のcompetence（力量、有能さ）から来た言葉です。人事の分野では「高業績者の行動特性」と訳されることが多く、成果を上げている人が、実際の仕事の場面でどう考え、どう動いているかを表します。

労働政策研究・研修機構の『日本労働研究雑誌』（2015年4月号）では、特定の職務をうまくこなすのに必要な、観察や測定ができる個人のスキル・行動・知識などとして説明されています。要になるのは「観察や測定ができる」という部分。性格や印象ではなく、行動として確かめられるものを指します。

スキルセットとの違いや、採用・評価・育成での使い分けは「[コンピテンシーとスキルセットの違い](/posts/competency-vs-skillset/)」で解説しています。この記事では、言葉の成り立ちと、種類の分け方を中心に扱います。

## 言葉が生まれた経緯

| 年 | 出来事 |
|---|---|
| 1959年 | 心理学者ホワイトが、環境にうまく働きかける力を「コンピテンス」と呼ぶ |
| 1973年 | マクレランドが、知能テストより成果に結びつく力を測るべきだと論文で主張 |
| 1982年 | ボヤツィスが『The Competent Manager』で管理職のコンピテンシーを研究 |
| 1993年 | スペンサー夫妻が『Competence at Work』で定義・辞書・面接の方法をまとめる |
| 1997〜2003年 | OECDのDeSeCoプロジェクトが「キー・コンピテンシー」を定める |
| 1990年代後半以降 | 日本企業で、能力考課の基準を職務遂行能力からコンピテンシーに置き換える動きが進む |

出発点は、マクレランドが1973年に『American Psychologist』誌に書いた論文です。知能テストや学校の成績は仕事での成果をうまく予測できていないと批判し、成果に結びつく力を直接測るべきだと主張しました。

その考え方を企業で使える形にしたのが、マクレランドと研究を続けたスペンサー夫妻です。1993年の著書では、コンピテンシーの定義、20項目の辞書、高業績者から行動を聞き出す面接の方法までをまとめています。

日本では、1990年代後半以降、能力考課の基準を職務遂行能力からコンピテンシーに置き換える企業が増えたと分析されています（福井直人「日本企業における能力考課基準の変容」）。

## 似た言葉との立ち位置

| 言葉 | 指すもの | 主な使われ方 |
|---|---|---|
| 知識 | 仕事に必要な情報や理論 | 試験、資格 |
| スキル | 訓練や経験で身につく技術・技能 | 育成計画、配置 |
| アビリティ | 後から身につけにくく、変わりにくい能力 | 適性検査 |
| 職務遂行能力 | 職位に応じた仕事全般をこなす力（持っている能力） | 職能資格制度、職能給 |
| コンピテンシー | 成果を上げる人の行動の特性（発揮された能力） | 採用面接、能力評価 |
| コア・コンピタンス | 会社の競争力の中核となる能力 | 経営戦略 |
| キー・コンピテンシー | 社会で生きていくために誰にでも必要な力 | 教育政策 |

アビリティは、厚生労働省の職業情報提供サイト（job tag）の言い方です。2024年の改訂で、職業ごとの「しごと能力プロフィール」にアビリティ35項目が加わりました。

名前が似ていても、コア・コンピタンスは会社の能力、キー・コンピテンシーは教育や社会の言葉です。人事評価で使うのは、個人の行動を指すコンピテンシーのほう。

### 職務遂行能力との違い

日本の多くの会社は、長く「職能資格制度」で社員を格付けしてきました。日経連（現在の経団連）が1969年の『能力主義管理』で、職務に応じた資格制度の導入を提起したのが土台です。

職能資格制度が見るのは、職位に応じた仕事全般をこなす力です。過去の積み重ねと将来の伸びしろを合わせて評価し、賃金も「部長ができる能力」、つまり持っている能力に応じて決める考え方をとります。

| | 職務遂行能力 | コンピテンシー |
|---|---|---|
| 対象 | 職位に応じた仕事全般 | 特定の職務 |
| 見るもの | 持っている能力（過去の蓄積と将来性） | 実際に発揮された行動 |
| 生まれ | 日本の職能給 | 米国の職務給 |
| 決め方 | 人事考課の結果に勤続年数を加味しがち | 高業績者の行動を分析して決める |

職務遂行能力は基準があいまいになりやすく、評価が人柄全体の印象に寄りがちだと指摘されてきました。行動で確かめられるコンピテンシーが注目されたのは、その弱点を補えるからです。

## コンピテンシーの種類（5つの分け方）

### 1. 層で分ける：氷山モデル

スペンサー夫妻は、コンピテンシーを知識・スキル・自己概念・特性・動機の5つの層に分けました。知識とスキルは水面の上にあって見えやすく、自己概念・特性・動機は水面の下にあって見えにくい部分です。

層ごとの説明は「[コンピテンシーとスキルセットの違い](/posts/competency-vs-skillset/)」に載せています。人事で「コンピテンシー」と言うときは、水面の下から行動として表れる部分を指すのが普通です。

### 2. 役割で分ける：基準コンピテンシーと差別化コンピテンシー

スペンサー夫妻は、役割の違いでも2つに分けています。1つは、その仕事を最低限こなすのに誰もが必要とする基準（しきい値）コンピテンシー。もう1つは、高業績者と平均的な人を分ける差別化コンピテンシーです。

経理担当者でいえば、締め日までに入力を終えるのは基準のほう。数字の動きに気づいて、聞かれる前に社長へ報告するのは差別化のほうです。採用の足切りや新人の目標には基準を、昇格の判断には差別化を使います。

### 3. 中身で分ける：6つの領域と20項目

スペンサー夫妻は、多くの職務の研究をもとに、コンピテンシーを6つの領域・20項目の辞書にまとめました。

| 領域 | 含まれる項目 |
|---|---|
| 達成・行動 | 達成志向、秩序・品質・正確性への関心、イニシアチブ、情報収集 |
| 援助・対人支援 | 対人理解、顧客サービス志向 |
| インパクト・対人影響力 | インパクトと影響力、組織の理解、関係構築 |
| 管理 | 他者の育成、指導・指示、チームワークと協力、チームリーダーシップ |
| 知的 | 分析的思考、概念的思考、専門性 |
| 個人の効果性 | 自己管理、自信、柔軟性、組織へのコミットメント |

自社の項目をゼロから考えるより、この表から3〜5個を選び、自社の言葉の行動の文に直すほうが早くできます。

### 4. 使う範囲で分ける：全社共通・職種別・階層別

会社で使うときは、範囲で3つに分けるのが一般的です。全社員に共通する項目、職種ごとの項目、階層（一般社員・リーダー・管理職）ごとの項目です。全社共通の項目は「コア・コンピテンシー」と呼ばれることもあり、会社のバリュー（行動指針）から決めます。

厚生労働省の職業能力評価基準も、職種に共通する能力と、職務ごとに固有の能力を分けて示しています。職種別の項目をつくるときの下敷きになります。

階層別の公的な例は、国家公務員の人事評価です。係員から事務次官まで職制上の段階ごとに「標準職務遂行能力」が定められ、課長補佐なら倫理、企画・立案と事務事業の実施、判断、説明・調整、業務遂行、部下の育成・活用といった項目が並びます。

名前は職務遂行能力ですが、評価は実際にとられた具体的な職務上の行動を踏まえて行う仕組み。中身はコンピテンシーに近いものです。

### 5. 社会での広がり：キー・コンピテンシー

コンピテンシーは、職場の外でも使われるようになりました。OECDは1997年から2003年にかけてのDeSeCoプロジェクトで、誰にでも必要な力を「キー・コンピテンシー」として定めています。

文部科学省の資料では、その3つのカテゴリーを、社会・文化的、技術的ツールを相互作用的に活用する能力、多様な社会グループにおける人間関係形成能力、自律的に行動する能力と訳しています。国際的な学力調査（PISA）の枠組みのもとになった考え方です。

職場向けでは、経済産業省の「社会人基礎力」（2006年）も、業種を問わない行動の物差しとして使えます。

## コンピテンシーの測り方

代表的な方法が、スペンサー夫妻の本で一章を割いて説明されている行動事例面接です。高業績者と平均的な人に、うまくいった場面とうまくいかなかった場面を詳しく語ってもらい、そのとき何を考え、何をしたかを比べます。

評価に使うときは、同じ項目の中に段階を文で書いておくと付けやすくなります。たとえば「指示されて動く」「自分から動く」「周りを巻き込んで動く」「仕組みを変える」のような並びです。

## よくある誤解

### 「知能テストより確かに成果を予測できる」

マクレランドの主張には、後に批判も出ました。1991年にバレットとデピネットは、同じ『American Psychologist』誌で文献を見直し、主張を支える証拠は限られていると結論づけています。

コンピテンシーは、知能より優れた予測の道具として証明されたわけではありません。成果につながる行動を言葉にし、社内で共有して育てる道具。そう割り切って使うのが現実的です。

### 「性格を評価するもの」

水面の下にある動機や特性を直接点数にすると、人格の評価になり、本人も納得しにくくなります。点を付けるのは、あくまで観察できる行動のほう。動機や特性は、行動の理由を考えるときの手がかりにとどめます。

### 「一度決めれば何年も使える」

過去の高業績者の行動をもとにする以上、事業や環境が変わると項目も古くなります。年に1回は、今の仕事で成果を上げている人の行動と合っているかを見直します。

## ひとことで言うと

> ポイント：コンピテンシーは「成果を上げる人の行動の特性」。持っている能力を見る職務遂行能力と違い、発揮された行動を見ます。分け方は、層・役割・中身・使う範囲・社会での広がりの5つ。性格ではなく行動を評価し、年1回見直します。
