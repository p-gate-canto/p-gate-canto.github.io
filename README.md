# 税理士のしおり

公開URL：https://p-gate-canto.github.io/

## 記事の書き方（おすすめ：Pages CMS）

1. https://app.pagescms.org を開き、`p-gate-canto.github.io` を選ぶ
2. 「記事」→「新規作成」。本文には最初から型（結論→根拠→言い換え→注意点）が入っている
3. 「下書き」をオンのまま保存すると、1〜2分後に **https://p-gate-canto.github.io/drafts/** で見た目を確認できる（検索には出ない）
4. 問題なければ「下書き」をオフにして保存 → 1〜2分で公開

### 本文で使える書き方

| 書き方 | 表示 |
|---|---|
| 引用ブロックで `結論：〜` | 濃紺の「結論」ボックス |
| 引用ブロックで `ポイント：〜` | 緑の「ポイント」ボックス |
| 引用ブロックで `注意：〜` | オレンジの「注意」ボックス |
| 引用ブロックで `補足：〜` | グレーの「補足」ボックス |
| 大見出し（##）を3つ以上 | 記事の先頭に目次が自動で付く |

### 自動で付くもの

- 読了時間、関連記事（同じ項目→同じ分野→同じタグの順）、前後の記事、筆者欄
- 法令の基準日から1年以上たった記事には、注意書きが自動で出る（毎週月曜に再チェック）
- 項目を選べば、分野が違っていても自動で補正される

## PCで作業する場合

| ファイル | 使いどき |
|---|---|
| `sync.bat` | Claude にデザイン変更などを頼む前にダブルクリック（GitHub の最新内容を取り込む） |
| `publish.bat` | PC 側の変更を公開するときにダブルクリック（取り込み→記録→送信を一度に行う） |

### 分類のしくみ

| 項目 | 内容 | 定義ファイル |
|---|---|---|
| 大分類 | WORK / LEARNING / LIFE | `src/data/taxonomy.json` の pillars |
| 中カテゴリー（category） | 36個。WORKは理念→企業戦略→競争戦略→機能別戦略の4層 | 同 mids |
| 小カテゴリー（topic） | 169個 | 同 mids[].topics |
| タグ（tags） | 資格・読者・会社のステージ・業種・時事・視点。1記事に最大5個 | 同 tagGroups |
| 記事タイプ（type） | 解説・比較・手順・改正ニュース・用語解説・事例・学習記録・エッセイ・ツール紹介 | 同 types |

分類を変えたい場合は、`taxonomy.json` と `.pages.yml` の両方を直す（Claude に頼めば両方そろえて直す）。

## ツールを載せる

1. HTMLツールやExcelを `public/tools/フォルダ名/` に置く
2. 記事タイプ「ツール紹介」で記事を書き、本文からリンクする（ツールの一覧は /types/tool/ に自動で並ぶ）

## ファイル構成

| 場所 | 中身 |
|---|---|
| src/content/posts/ | 記事（.md） |
| templates/ | 記事テンプレート |
| public/tools/ | 自作ツール |
| src/consts.ts | サイト名・キャッチコピー・カテゴリ |
| src/styles/global.css | デザイン（色・文字） |
| .github/workflows/deploy.yml | 自動公開の設定（触らない） |
