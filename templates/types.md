---
title: 記事の型（テンプレート集）
---

記事タイプごとの見出しの型です。新しい記事の本文に、使う型をコピーして貼り付けてください。

本文の引用ブロックで「結論：」「ポイント：」「注意：」「補足：」から書き始めると、色付きの要点ボックスになります。

## 解説（explainer）

制度・論点の解説。

```markdown
## 結論

（ここに書く）

## 根拠（条文・通達・適用時期）

（ここに書く）

## ひとことで言うと

（ここに書く）

## 実務での注意点

（ここに書く）

## あわせて考えたいこと

（ここに書く）
```

## 比較・判断（comparison）

AとBのどちらがよいか。

```markdown
## 結論

（ここに書く）

## 比較表（メリット・デメリット）

（ここに書く）

## 判断の基準

（ここに書く）

## 推奨とその理由

（ここに書く）
```

## 手順・チェックリスト（checklist）

期限・提出先つきの手続き。

```markdown
## 結論

（ここに書く）

## 期限と提出先

（ここに書く）

## 手順

（ここに書く）

## チェックリスト

（ここに書く）

## よくある誤り

（ここに書く）
```

## 改正ニュース（news）

税制改正・法改正の速報。

```markdown
## 何が変わるか

（ここに書く）

## いつから

（ここに書く）

## 誰に影響するか

（ここに書く）

## やるべきこと

（ここに書く）

## 根拠

（ここに書く）
```

## 用語解説（glossary）

専門用語をひとことで。

```markdown
## ひとことで言うと

（ここに書く）

## 詳しく

（ここに書く）

## 使い方の例

（ここに書く）

## 関連用語

（ここに書く）
```

## 事例（case）

架空化した事例から学ぶ。

```markdown
## 状況

（ここに書く）

## 課題

（ここに書く）

## 打ち手

（ここに書く）

## 結果

（ここに書く）

## 学び

（ここに書く）
```

## 学習記録（study-log）

勉強の記録と振り返り。

```markdown
## 結論

（ここに書く）

## やったこと

（ここに書く）

## 結果（数字）

（ここに書く）

## 次の打ち手

（ここに書く）
```

## エッセイ（essay）

考え方・働き方の話。

```markdown
## 問い

（ここに書く）

## 考えたこと

（ここに書く）

## いまの答え

（ここに書く）
```

## ツール紹介（tool）

自作ツール・テンプレート。

```markdown
## できること

（ここに書く）

## 使い方

（ここに書く）

## 入手方法

（ここに書く）

## 注意点

（ここに書く）
```
